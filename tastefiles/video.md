# Taste brief — launch video

Written 2026-10-26 from Radu's answers. Read `tastefiles/site.md` first; the
framing, vocabulary (smooth / light / clean / findable / quotable), and hard
rejections there apply here too.

## Deliverables

1. **Launch film** — 30–40 s, 16:9, no voiceover. Music + kinetic type + real
   widget UI. Cutdowns at 1:1 and 9:16.
2. **Social loop** — 15 s, silent, seamless loop, 1:1 and 9:16.

Built with the HyperFrames skill stack (`hyperframes` entry point, gateway
`motion-doctrine`). Versioned renders; never overwrite a previous cut.

## Story

The human stays in control. An agent ships something that looks done →
VibeCheck notices what a glance can't (jank, bloat, leaks, SEO/AEO misses) →
you choose to send one finding → the agent fixes → fresh browser evidence turns
it green. End on the product name, `npm i @wcgw/vibe-check`, and the site URL.

## Look and motion

- Light editorial canvas matching the site; the widget is the dark object.
- Real UI only: capture the actual widget and demo app; no fake dashboards.
- One continuous camera move across scenes (motion-doctrine vector law); no
  idle wobble; stillness before the green "fixed" beat.
- Single-ink type. Red appears only on a real fault, green only on a verified
  fix.
- No print/proof motifs, no split-colour text, no invented numbers. Any number
  on screen must come from a real capture.
